客户端 API 调用说明

给第三方客户端 / 程序接入本服务

端点信息

项目值
Base URLhttp://192.168.31.221:8002/v1
认证方式Authorization: Bearer <你的API Key> （在「设置」页创建 Key）
对话接口POST /v1/chat/completions
查看模型GET /v1/models （OpenAI 标准格式，第三方客户端自动识别）
管理后台http://192.168.31.221:8002/admin

curl 调用示例

# 非流式对话
curl http://192.168.31.221:8002/v1/chat/completions \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false
  }'

# 流式对话
curl -N http://192.168.31.221:8002/v1/chat/completions \
  -H "Authorization: Bearer 你的APIKey" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.3",
    "messages": [{"role": "user", "content": "写一段快排"}],
    "stream": true
  }'

# 查看模型列表
curl http://192.168.31.221:8002/v1/models \
  -H "Authorization: Bearer 你的APIKey"

Python（OpenAI SDK）示例

from openai import OpenAI

client = OpenAI(
    base_url="http://192.168.31.221:8002/v1",
    api_key="你的APIKey",
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "讲个笑话"}],
)
print(resp.choices[0].message.content)

第三方客户端接入

配置项填什么

常见问题

现象处理
401 Invalid passwordAPI Key 错误，或 Authorization 头少了 Bearer 前缀
400 非法模型上游临时拒绝该模型快照，代理已自动降级重试；仍失败则换一个模型或稍后再试
413 请求体过大上游限制约 1MB，精简对话历史或拆分请求
401 no usable account所有健康账号本轮不可用，去「账户管理」查看状态/刷新 token
